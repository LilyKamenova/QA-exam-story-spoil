# Story Spoil – QA Exam Summary

This is a summary of the exam tasks I worked on for the QA Fundamentals & Manual Testing course.

## Objective
The goal was to test a web application called **Story Spoil**.  
I was tasked with:

- Creating manual test cases for 6 use cases:
  1. Home Page
  2. User Registration
  3. User Login
  4. Profile Management
  5. Spoiler Creation
  6. Spoiler Management (edit, delete, search)

- Executing at least 15 test cases and documenting the results
- Reporting at least 5 bugs (including 2 high/critical severity)
